# Product

<!-- impeccable:product-schema 1 -->

## Platform

wow-addon

Not web, iOS or Android: a World of Warcraft addon running inside the WoW Forever game client (Interface 16001), drawn with the client's Lua frame API (frames, textures, font strings). No HTML, no CSS, no browser.

## Users

World of Warcraft players leveling a character from 1 to 60 on WoW Forever, a mix of players new to classic leveling and returning veterans. They read the guide window in glances while playing: walking, fighting, talking to NPCs. The window sits over the moving game world for hours at a time.

## Product Purpose

An automatic leveling guide: it shows what to do next and where to go, and moves on by itself when the game confirms the step is done. Success is a player who logs in, follows the arrow and the cards, and reaches 60 without opening a website or typing a command.

## Positioning

Routes for all 56 race and class combinations, generated by the project's own tools from open quest data (QuestieDB, GPLv3) and client tables, then checked by a validator and played from 1 to 60 in a simulator before every release. Written independently of other guide addons (see docs/INDEPENDENCE-REVIEW.md).

## Operating Context

- The game client's default UI is around it: action bars, unit frames, minimap, chat, quest log, the world map.
- Windows: the guide window (header, card stack, step list, footer), the arrow, map and minimap pins, item and target buttons, menus, the setup wizard, the settings panel in the game's options, the minimap button.
- Released through GitHub tags to GitHub Releases and CurseForge (docs/RELEASING.md).

## Capabilities and Constraints

- Lua 5.1 in the WoW client. Textures are the addon's own .tga files (generated by tools/gen_textures.js) or solid colors; no gradients API beyond what the client offers; no CSS effects.
- Fonts are set by file only (SetFont); SetFontObject with anything but the client's own named font objects crashes the Forever client.
- Protected functions and secure frames: nothing secure changes in combat; some calls (for example SetRaidTarget) are forbidden to addon code.
- Windows must never open off screen and must be movable, resizable, scalable and lockable.
- Every design value lives in DESIGN.md and NoirGuides/UI/Theme.lua together; tools/test-lua/theme.lua fails when they differ.
- A mock game client and simulator (tools/harness, tools/sim_all.js) test everything; the real look can only be seen in the game.

## Brand Commitments

- The name Noir Guides stays. The look need not be dark because of the name.
- The class color accent (0.2.2): the accent follows the player's class, with a gold option.
- The structure stays: header, card stack, step list, footer.
- It should feel at home next to WoW's own default frames, not like a separate app pasted over the game.
- Standing visual preference (chosen 2026-11-13): the category standard, the game's own tooltip panel executed at full craft. Quality bar: ElvUI and WoW's own tooltips. Background darkness is the player's choice (an opacity setting).

## Product Principles

1. Glanceable first: a player mid-fight reads the current step in one look.
2. The window tells the game's truth: never marks a step done or hides one on its own judgment.
3. Independence: nothing copied from other guide addons; routes and steps come from this project's data and tools.
4. Automation stays in the player's hands: every automatic action has its own switch.

## Accessibility & Inclusion

- Shape before color: kinds differ by icon and the current pin by shape, so meaning survives color blindness.
- Text at 4.5 to 1 contrast or better on the surface it sits on; a large font size option.
